# Marca AiUDA

**AiUDA** = marca madre (escritura: *AiUDA*; «ayuda» en español, «AI» dentro). Cada especialidad lleva el prefijo AiUDA y un apellido que dice qué hace. Siempre en español primero.

## Propuestas de familia (elegir una línea; recomendada: A)

### Línea A — Descriptiva (recomendada: clara, buscable, escalable)
| Producto | Qué hace |
|---|---|
| **AiUDA Social** | Community manager: plan del mes, piezas, publicación |
| **AiUDA Ads** | Anuncios automáticos Meta, TikTok y Google |
| **AiUDA Inbox** | Comentarios y mensajes con respuestas IA y captura de leads |
| **AiUDA Studio** | Creación de imagen, video, reels y avatar UGC |
| **AiUDA Insights** | Métricas, competencia y lecturas |
| **AiUDA Setup** | Diagnóstico y configuración personalizada del negocio |
| **AiUDA Agency** | Modo agencia / white-label |

### Línea B — Roles humanos (cálida, memorable)
AiUDA Manager · AiUDA Media (anuncios) · AiUDA Responde (inbox) · AiUDA Creativo · AiUDA Analista · AiUDA Onboarding.

### Línea C — Cortas (mejor para marca registrable)
AiUDA Pulse (insights) · AiUDA Spark (contenido) · AiUDA Boost (ads) · AiUDA Echo (respuestas) · AiUDA Forge (estudio) · AiUDA Compass (diagnóstico).
